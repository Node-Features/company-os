# Feature Documentation

This directory contains decision and validation evidence for significant features without burdening trivial changes.

| Document | Purpose | Status | Read when |
|---|---|---|---|
| `<feature-id>/README.md` | Feature problem, scope, and status | NOT YET SPECIFIED | Read when orienting to a significant feature. |
| `<feature-id>/design.md` | Smallest defensible vertical design | NOT YET SPECIFIED | Read before implementing the feature. |
| `<feature-id>/reference-analysis.md` | Relevant source-based research | NOT YET SPECIFIED | Read when a design borrows external patterns. |
| `<feature-id>/threat-model.md` | Feature-specific threats and controls | NOT YET SPECIFIED | Read during security review. |
| `<feature-id>/test-plan.md` | Required validation and evidence | NOT YET SPECIFIED | Read before implementation and review. |
| `<feature-id>/retrospective.md` | Outcomes and lessons after delivery | NOT YET SPECIFIED | Read after the feature is completed. |
